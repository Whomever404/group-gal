# 01 · 项目总览

## 1. 项目定位

`group-gal` 是一个**把真实群聊改写成文字恋爱冒险（Galgame）**的整活项目：

- **输入**：两批 QQ 群聊记录（`members.zip`，5,325 条消息 / 52 名发言者 / 80 人名册）+ 一份群氛围与成员画像分析报告（`report.pdf`，23 页）。
- **输出**：**单文件、离线、零运行时依赖**的网页游戏——玩家扮演「第 81 位群友」入群，在一群嘴硬心软的人中间选择怎么说话，最后走向 15 条角色线之一，并可在「结局回收室」收集 23 个坏结局。
- **风格**：游戏界面是 **QQ 群聊客户端**（桌面三栏 / 窄屏单栏），标题页与结局页是 **galgame 排版**；所有立绘为 SVG 剪影、BGM 由 Web Audio 实时合成——**不引用任何外部图片 / 音频资源**。

## 3. 版本谱系

项目一共走过三代：

| 代 | 形态 | 定位 |
|----|------|------|
| v0.2 / 豆包版 / v1.0 / v2.0 | **单文件 HTML**（`group-chat-galgame*.html`、`啥子豆包版本.html`） | 从早期整活 Demo 到 v2.0「剧情全部重写」的完整版；世界观、角色、机制都在这一代成型 |
| remake 重写版 | **Vite + TypeScript 工程**（LanGYou 的两个 PR） | 把剧本数据与引擎从 DOM 里拆出来：引擎零 DOM、剧本图校验器、回想 / 多槽存档 / 设置 / 路线图 |
| **本版（统一版）** ★ | 同一个仓库根目录的工程 + 单文件产物 | **取 remake 的引擎与界面，取我们的剧本与夜间运营机制**，合并为一版；旧的两套并行目录不再存在 |

单文件历史版本仍然保留在仓库根目录，可以双击直接玩，作为「当初长什么样」的存档。

## 4. 技术栈与设计约束

| 维度 | 选择 | 原因 |
|------|------|------|
| 形态 | 构建产物是**单个 `.html`**（JS/CSS 全内联） | 双击即玩、方便转发、便于截图整活 |
| 语言 | TypeScript（strict）+ Vite 7 | 剧本规模已经超过人肉能记住的限度，需要编译期与校验期两道网 |
| 渲染 | DOM + CSS 动画 + 内联 SVG 剪影 | 不引用外部图片资源 |
| 音频 | Web Audio API 实时合成（4 条曲目 + 音效） | 免版权、离线可播 |
| 持久化 | `localStorage`（3 个手动槽 + 自动存档 + 设置） | 无后端；`file://` 下同样可用 |
| 分发 | `./start.sh` 起本地服务器，或直接双击单文件 | 两种都行，互不依赖 |

## 5. 玩法概述

```
标题画面（开始游戏 / 结局回收室 / 音乐 / 关于）
        │
        ▼
序章 → 第一章 新人报道 → 第二章「群日常」（回合循环运营）
        │                    首轮：从 15 条全员支线里锁定一名攻略对象
        │                    此后每回合：TA 的本命支线 + 1~2 条随机事件
        │                    羁绊达标或支线走完 → 解锁「推进主线」
        ▼
      第三章 躲猫猫之夜 → 第四章 分岔之夜
        ├─「空気」≥3 → BE：第 81 人 END（没有人记得你来过）
        └─ 走已锁定对象（未锁定则羁绊最高者）的 15 条角色线 → GOOD END
```

核心系统：

- **羁绊**：选项为角色加减好感；顶栏与「群成员」抽屉可实时查看（无视 → 眼熟 → 嘴替 → 宝宝 → 沦陷）。
- **资质**：真诚 / 嘴臭 / 卖弱 / 空気 / 水群 五项，选项与事件都会结算，顶栏实时显示；**空気 ≥ 3 会改变结局判定**。
- **夜间运营**：第二章是回合循环中枢——首轮全员候选（选中即锁定，羁绊 +2），锁定后每回合只出当前对象的支线 + 至多 2 条随机事件（日常为主、少量风险）；羁绊阈值 12 或两段支线走完即解锁推进。
- **复读**：复读上一条群消息、水群值 +1；同一句连刷 3 次触发「刷屏 END」。
- **推进**：默认按文字速度自动推进（像真的群一样自己往下滚），点击消息流或按空格 / 回车可立刻推进当前这一句。
- **存档**：自动存档（每次抵达选择点）+ 3 个手动槽；引擎侧格式版本 `SAVE_VERSION = 3`，v1 / v2 老存档会自动补齐字段。
- **结局回收室**：23 个坏结局 + 15 条角色线好结局的收集进度，未解锁的只显示占位。

## 6. 素材来源与免责声明

- `members.zip`：QQ 客户端导出的聊天记录（含昵称、群名片、角色、时间戳、消息文本，图片 / 表情 / 文件以占位形式保留）。
- `report.pdf`：对上述记录的成员画像与风险分析（嘴臭即亲密、卖弱成瘾、性压抑边界、AI 依赖、小圈子排外等十类问题）。
- `skills/immortals/`：20 位群友的「数字永生」人设包（由语料蒸馏而来），是本版剧本台词的主要依据。
- 游戏中所有角色**均基于群内可见行为的二次虚构**，与现实人物无关。
