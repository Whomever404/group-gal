# 群友 Skill 熔炼 · 新数据库版（独立任务）

> 基于 2026-10 上传的**新群聊数据库**（QQ 群「【里】😂群聊 | 行」，2026-07-12 ~ 2026-10-12，**214,905 条消息**）
> 为 **21 位群友**逐一熔炼独立的 skill 包，并建立**习惯用语库**与**群梗库**。
> ⚠️ 本任务是独立产出：分析只使用本次上传的数据（群聊记录 + QQ 号对照表 + immortal-skill 模板），**未参考仓库内任何其他资料**。

## 三、核心方法（要点）

1. **复读检测（本任务的关键要求）**：把时间序上**连续的同内容消息**（文本或表情/图片签名一致、间隔 ≤15 分钟）识别为复读链；链内**第一条记给第一位群友（原创主）**，其余发送者记「复读跟随」并被打上**「喜欢复读」标签**（分级见下）。共检出 3,541 条链（多人链 3,376 条）。
2. **归属隔离**：复读跟随消息**从跟随者的内容池剔除**——即跟随者不会因为复读而「占有」这条短语；统计只归于原创主与其本人原创消息（满足「每个群友单独分析、不混淆」的要求）。
3. **连发折叠**：同一人 3 分钟内重复发送同一内容只计 1 次，避免刷屏虚增频次。
4. **逐人独立分析**：每人单独统计活跃时段（北京时间）、媒体使用、回复/@ 网络（谁与谁互动，精确到人对人）、短语辨识度（log-odds：该成员的用语 vs 全群背景语料）、整句复现与生活事件候选。
5. **引文审计**：全部产出的 1,978 条「」引文均与原语料做过程序化比对（空白归一化 + 片段匹配），不吻合处逐条人工修正；无法确认含义的短语标注「含义待考（仅存频率证据）」。

### 复读标签规则

| 标签 | 条件 | 成员（跟随率） |
|------|------|----------------|
| **喜欢复读** | 跟随率 ≥3% 且 ≥30 次 | 蛋蛋 11.64%、ndylgywsz 7.42%、没关系，5元 6.85%、PW 4.34%、LanGYou 4.20%、硫酸铜 3.70%、黄油猫 3.23%、面包 3.23%、石蒜 3.06% |
| **有时跟复读** | 1.5%~3% | 根哥 2.33%、Tttt. 2.03%、闹七 1.95%、费的 1.86%、石斑鱼 1.81%、G哥 1.56% |
| **很少跟复读** | <1.5% | R哥 1.27%、taffy 1.24%、30586 1.16%、aka 1.07%、一条鱼 0.84%、藤原氏蘑菇汤 0.34% |

> 特别注记：**蛋蛋 = 全群复读跟随第 1（740 次）**；**闹七 = 被复读之王（原创主 637 次、跟随 601 次，绝对量双榜首）**。完整数据见 `习惯用语库.md` 与 `_evidence/复读统计-成员.json`。

## 四、怎么使用 skill 包

1. 读某人的 `SKILL.md` 获取入口与阅读顺序；按需加载 `personality.md`（性格/喜好）→ `interaction.md`（互动风格）→ `memory.md`（共同记忆）→ `phrasebook.md`（习惯用语）。
2. 让 AI 模仿说话风格时，建议以 `phrasebook.md` 的高频短语 + `personality.md` 的口头禅为骨架，`memory.md` 供回忆类场景。
3. `impression` 区（文件尾部 `---` 之后）是模型基于统计的推断，避免当作事实引用。

## 五、内容边界与伦理

- 所有内容均基于**群聊行为特征**的统计与摘录，属**二次虚构**性质，不代表当事人真实立场；不得用于对外冒充、跟踪或骚扰。
- 已做隐私处理：产出物中**不含 QQ 号**（仅 manifest 保留群标识）、**不含疑似真实姓名**（含疑似真名的昵称短语已替换为群昵称）。
- 群内高频脏话（「傻逼」「操你妈」等）是**语癖与起哄语境**，各文件中均标注为语言习惯而非人身评价。
- 数据窗口仅 92 天，语音/线下/私聊场景未覆盖；bot 指令与自动消息已从内容池剔除。
