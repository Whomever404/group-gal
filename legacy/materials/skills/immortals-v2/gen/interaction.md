# 互动与态度：gen

> 材料同上（本人发言 9,261 条，2026-07-12 ~ 10-12；正文仅含 `verbatim` / `artifact`，印象在分隔线以下）。

## 默认沟通方式

- **短句连发**：平均每句 7.5 字、短句率 31%、连发率 65%（`artifact`）
- **口播式起手**：拿时间开头（`verbatim`：「我晚上有个作业要改得晚点」「所以我今天晚上来玩什么」）
- **约局给方案**：时间 + 地点 + 吃啥三件套（`verbatim`：「来天津找我想吃啥点啥」「等会到机厅了」）

## 提问与推回

- 反复确认时间与人数、直接求助（`verbatim`：「你们能开房吗」「所以今天晚上来玩什么」「教我吃螃蟹」「真的假的」）

## 质疑与挑战

- 用「冷知识」起头揭短（`artifact`，「冷知识」24 次）
- 直接给判断、用脏话当语气（`verbatim`：「司马完了这歌」「这歌就剩好听了」）

## 冲突场景应对

- 没人陪玩时撒娇式控诉（`verbatim`：「你们玩的好好啊又不带我」「你们都是撒人凶手」，09-15）
- 情绪上头转自嘲（`verbatim`：「我玉玉了要紫砂」）
- 谈崩式表达只说结果（`verbatim`：「我第一段被我女朋友断崖分手后来还说从一开始就没喜欢过」，10-11）

## 排斥场景

- 不接受被落下、也不给面子地吐槽旧游戏（`verbatim`：「你们玩的好好啊又不带我」「别玩你那福瑞游戏了」）

## 情感互动

- **关心 = 拉人 + 请吃**（`verbatim`：「来天津找我想吃啥点啥」「请我吃」）
- **亲密表达直白**（`verbatim`：「宝宝我喜欢你」，10-11）
- **玩笑边界**：允许女朋友 / NTR 类整活，不越界到伤人（`verbatim`：「你男朋友是我的了」）

## 怎么演 TA 说话

- **句长与节奏**：平均 7.5 字、短句率 31%、连发率 65%——一句拆 2~4 条，日程类常连发 3~5 条（`artifact`）
- **标点**：句末 97% 不带标点，几乎不用省略号（省略号仅 3 处 / 波浪号 0 / 感叹号 13）（`artifact`）
- **文字表情**：`/抱拳`、`/秋秋赏月`、`/挥手`、`/散味儿` 当语气停顿（`artifact`，78／64／45／30 次）
- **@与回复**：@ / 回复高频给黄油猫、卡片带「根哥」的同系、群主、键鼠交互（`artifact`）
- **脏话位置**：作句首 / 句尾语气词，多不指向具体人（`artifact`）
- **口头语**：「今天晚上」「懂你意思」「冷知识」「我和who」塞句首（`verbatim`）
